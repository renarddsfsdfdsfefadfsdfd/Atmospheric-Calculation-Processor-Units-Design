cOne-line calls
import acpu
dev = acpu.ACPUDevice()

r = dev.forecast(
  model="l96", members=64,
  lead_days=10, precision="adaptive")

print(r.rmse, r.energy_j, r.seconds)
The same call exists in JavaScript, on the CLI and over HTTP; the console in the app parses forecast(members=64, lead_days=10).
dDriver interface
callmeaning
ACPI_DEV_INFO64 tiles, clocks, temperature
ACPI_LOADAVISA binary + constants
ACPI_RUNstart a job, returns job id
ACPI_POLLprogress, energy, Tj
ACPI_READDMA result buffers
ACPI_ECCcorrected / uncorrected counts
The virtual device in the app implements the same seven calls, so code written against it runs unchanged on silicon.
